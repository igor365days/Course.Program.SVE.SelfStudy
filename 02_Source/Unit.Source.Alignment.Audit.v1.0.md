## Integrity note

The Unit/LCP/CP architecture is project design. The source-derived structure map is the canonical bridge between the scanned book and the project route. Direct page verification establishes evidence for canonical content; it does not imply that the book itself defines our Unit boundaries.

The PDF is image-based. Verification was therefore performed by direct inspection of rendered source pages. Automated text extraction was not treated as authoritative where incomplete or garbled.
