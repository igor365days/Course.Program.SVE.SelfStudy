## Verification scope

`SOURCE_ALIGNED` means that the Unit definition matches the source-derived structure map and does not omit a topic explicitly represented there.

It does **not** mean that every exercise, example, lexical item or page-level detail of the scanned source book has been independently transcribed and verified. The scanned PDF is image-based and its automated text extraction is incomplete. No unverified source detail has been invented to fill that gap.

Therefore the current status is:

- Route structure: **VERIFIED**.
- 56 Unit source-map alignment: **SOURCE_ALIGNED**.
- Lesson 1 page-level verification: **VERIFIED**.
- Full page-by-page verification of Lessons 2–18: **PENDING**.
- Assessment components of LCP/CP: **PENDING separate verification**.

## Integrity rule

The book does not define the Unit/LCP/CP architecture. Unit boundaries remain explicit project design. Source-derived content must not be silently replaced by general linguistic knowledge; project-added pedagogical material must remain identifiable.
