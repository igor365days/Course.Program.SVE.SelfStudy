**Источник:** Е. Л. Жильцова, «Шведский язык. Самоучитель», 2-е издание, Москва, «Живой язык», 2014.  
**Основание:** непосредственно присланный пользователем PDF `Шведский язык, самоучитель_copy(1).pdf`.  
**Статус:** `CANONICAL_SOURCE_MAP`

## Правило источника

Этот файл является **единственной канонической картой содержания книги** в проекте.

Карта составлена непосредственно по разделу «Содержание» присланного PDF. Она фиксирует структуру и содержание, заявленные самой книгой.

`Unit`, `LCP`, `CP`, `Section` и другие элементы архитектуры проекта **не являются структурой книги**. Они определяются отдельными каноническими документами проекта и должны ссылаться на эту карту как на первичный источник.

Прежняя производная декомпозиция книги больше не является источником истины и не используется для разрешения расхождений.

## Правила использования карты

1. Этот файл — единственный источник истины для **структуры книги**.
2. При любом расхождении производного проектного файла с этой картой приоритет имеет эта карта.
3. При необходимости фактической проверки содержания приоритет имеют страницы присланного PDF.
4. Проектные `Unit/LCP/CP` не добавляются в эту карту и не должны использоваться для «исправления» содержания книги.
5. Новая альтернативная карта книги не создаётся без отдельного архитектурного решения пользователя.
