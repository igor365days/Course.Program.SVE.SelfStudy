## 1. Правило источника

Этот файл является **единственной канонической картой содержания книги** в проекте.

Карта составлена непосредственно по разделу **«Содержание»** присланного PDF. Она фиксирует структуру, названия уроков, заявленные книгой темы и номера печатных страниц.

`Unit`, `LCP`, `CP`, `Section` и другие элементы архитектуры проекта **не являются структурой книги**. Они являются проектной декомпозицией и обязаны ссылаться на эту карту.

Прежняя производная карта/декомпозиция не является источником истины и не может использоваться для разрешения расхождений.

## 2. Критическое ограничение текущего PDF

Файл PDF содержит **150 PDF-страниц**. На последней доступной странице виден печатный номер **146**. Следовательно:

- содержание книги в PDF позволяет построить карту всех 18 уроков;
- тело книги в текущем PDF доступно только до печатной стр. 146;
- Урок 13 доступен частично (печатные стр. 140–146 из заявленных 140–149);
- печатные стр. 150–224 отсутствуют в текущем PDF;
- Уроки 14–18 поэтому пока имеют **структурную запись по «Содержанию»**, но не могут считаться проверенными по тексту/сканам тела книги.

Это ограничение не является основанием для остановки работы: всё, что можно достоверно установить из доступного PDF, фиксируется сейчас; недоступные участки получают явный статус ожидания источника.

## 5. Правило дальнейшей работы

Любой проектный элемент, основанный на книге, должен иметь трассировку:

`Project element → Lesson → item(s) of this map → printed page(s) → available source evidence`

Если печатная страница находится за пределами текущего PDF, статус должен быть `SOURCE_NOT_AVAILABLE` и материал нельзя выдавать за проверенный по источнику.

Если содержание заявлено в «Содержании», но тело страницы недоступно, разрешается использовать его только как **структурное утверждение книги**, а не как доказанную по тексту формулировку.
