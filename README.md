# Course.Program.SVE.SelfStudy

Отдельный учебный проект по шведскому языку на основе книги **Е. Л. Жильцова, «Шведский язык. Самоучитель» (2-е изд., 2014)** и методического опыта проекта `Course.Program.SVE`.

## Назначение

Проект не заменяет и не изменяет основной `Course.Program.SVE`. Он представляет собой самостоятельный экспериментальный курс, в котором книжный материал перерабатывается в последовательную систему обучения.

## Принцип

**Книга → анализ → учебная программа → учебные блоки → практика → проверка результата → состояние курса.**

Существующий курс `Course.Program.SVE` используется только как источник накопленного методического опыта. Структура нового курса проектируется независимо.

## Текущий этап

1. Создан отдельный репозиторий.
2. Зафиксирована архитектура проекта.
3. Следующий этап — полный анализ исходной книги.
4. После анализа будет сформирована первая версия программы курса.

## Структура

- `00_Project/` — спецификация и методика проекта.
- `01_Course/` — программа и состояние курса.
- `02_Source/` — анализ исходной книги.
- `03_Lessons/` — разработанные учебные блоки.
- `04_Resources/` — дополнительные ресурсы.

## Правило версий

До завершения анализа книги не фиксируется окончательное количество уроков нового курса. Нумерация и гранулярность будут определены после анализа содержания.
