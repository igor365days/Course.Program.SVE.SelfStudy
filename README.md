# Course.Program.SVE.SelfStudy

Канонический проект самостоятельного курса шведского языка на основе книги **Е. Л. Жильцова, «Шведский язык. Самоучитель» (2-е изд., 2014)** и накопленного методического опыта проекта `Course.Program.SVE`.

## Назначение

Репозиторий хранит **каноническое определение курса**: его структуру, программу, учебные единицы, планы занятий, методику и необходимые ресурсы.

Практическое прохождение конкретным учащимся не хранится здесь. Оно ведётся в соответствующем ChatGPT Project.

## Основной принцип

**Канонический курс → учебная единица → обучение → практика → проверка → результат обучения.**

GitHub отвечает на вопрос:

> **Что и в какой последовательности должен изучать учащийся?**

ChatGPT Project отвечает на вопрос:

> **Как конкретный учащийся проходит этот курс и каков его текущий результат?**

## Текущая версия

`Course.Program.SVE.SelfStudy v1.0`

Каноническая программа содержит:

- 18 исходных уроков книги;
- 56 основных учебных единиц;
- 5 контрольных точек.

Таким образом, канонический маршрут содержит 61 структурный элемент.

Границы учебных единиц сохраняются как часть утверждённой структуры курса и не должны изменяться ради удобства организации ChatGPT.

## Структура репозитория

- `00_Project/` — спецификация, цели, методика и регламенты AI.
- `01_Course/` — каноническая программа курса.
- `02_Source/` — анализ исходной книги.
- `03_Lessons/` — канонические планы и спецификации учебных единиц.
- `04_Resources/` — необходимые и дополнительные ресурсы.

## Разделение данных

**GitHub:** содержание и архитектура курса.

**ChatGPT Project:** состояние конкретного прохождения, результаты, ошибки, повторение и рабочие чаты.

Состояние обучения учащегося не изменяет канонический курс.

## Версионирование

Изменения канонической программы оформляются как изменения версии курса. Рабочие изменения, не меняющие структуру маршрута, не должны смешиваться с состоянием конкретного обучения.
