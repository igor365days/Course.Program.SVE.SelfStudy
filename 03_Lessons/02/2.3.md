# Unit 2.3 — Члены предложения и типы предложений

**Unit ID:** 2.3

**Section:** 1  
**LCP:** LCP-02  
**Source pages:** 17–19

## Learning Objective
Распознавать основные члены и типы предложений и применять их в простых конструкциях.

## Canonical Content
Подлежащее; сказуемое; дополнение; определение; обстоятельство; типы предложений по цели высказывания; типы предложений по составу; двусоставные, безличные и неопределённо-личные конструкции.

## Learning Sequence
Введение → разбор функций членов предложения → классификация типов → работа с примерами источника → самостоятельный разбор и построение → проверка.

## Practice Requirements
Разбирать и самостоятельно строить простые предложения разных типов, включая повествовательные, вопросительные и побудительные модели.

## Verification Criteria
Учащийся правильно определяет функции элементов и строит заданные модели предложений.
