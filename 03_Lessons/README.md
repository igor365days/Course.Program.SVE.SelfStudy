# Lessons

Здесь будут храниться разработанные учебные блоки нового курса.

Учебные блоки создаются после анализа исходного материала и утверждения структуры программы.

Каждый урок должен содержать цель, исходный материал, ожидаемый результат, этапы обучения, практику, проверку, условия завершения и необходимые ресурсы.
