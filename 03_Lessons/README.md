# Canonical Lesson Definitions

## Назначение

Каталог `03_Lessons` содержит канонические определения всех учебных единиц и контрольных точек курса `Course.Program.SVE.SelfStudy`.

Это не журнал прохождения обучения и не история работы пользователя.

Каноническое определение отвечает на вопрос:

> **Что должна обеспечить данная учебная единица и каким образом должно быть проверено её освоение?**

Фактическое прохождение конкретным пользователем хранится в ChatGPT Project и его Learning Progress.

## Структура

Курс содержит:

- 56 канонических Unit;
- 5 контрольных точек (CP).

Структура каталогов соответствует блокам курса:

```text
03_Lessons/
├── 01/
│   ├── 1.1.md
│   ├── 1.2.md
│   └── ...
├── 02/
│   └── ...
├── ...
└── 18/
    └── ...
```

Контрольные точки хранятся в соответствующем блочном каталоге с именами `CP-1.md` … `CP-5.md`.

Идентификаторы Unit (`1.1` … `18.4`) являются стабильными идентификаторами учебных элементов и должны совпадать с идентификаторами в канонической программе.

## Стандарт Unit

Каждый файл Unit должен соответствовать `00_Project/Unit.Definition.Standard.md`.

Минимально он должен определять:

- Identity;
- Place in Course;
- Learning Objective;
- Canonical Content;
- Learning Sequence;
- Practice Requirements;
- Verification Criteria;
- Typical Difficulties;
- Transition;
- Canonical References.

Файл описывает **план и требования к обучению**, а не фактический результат конкретного пользователя.

## Стандарт Checkpoint

Контрольная точка является каноническим элементом маршрута, но не книжным уроком.

Её определение должно содержать:

- охватываемые Unit;
- цели интеграционной проверки;
- проверяемые знания и навыки;
- формат проверки;
- критерии прохождения;
- правила корректирующей работы при выявлении существенных пробелов.

## Связь с другими слоями

```text
01_Course/
    ↓ определяет маршрут
03_Lessons/
    ↓ определяет каждую Unit и CP
ChatGPT Project
    ↓ организует фактическое прохождение
Learning Progress
    ↓ фиксирует фактический результат
```

`03_Lessons` не должен содержать индивидуальные данные пользователя, историю чатов или текущий прогресс обучения.

## Правило каноничности

Учебные единицы не объединяются, не разделяются и не перестраиваются ради удобства ChatGPT Project.

Если изменяется назначение, содержание, последовательность или критерии Unit, это является изменением канонического курса и должно быть отражено в соответствующей версии программы.
