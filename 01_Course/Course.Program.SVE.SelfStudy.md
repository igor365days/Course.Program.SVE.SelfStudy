# Course.Program.SVE.SelfStudy

**Status:** проектирование

**Версия:** 0.1-draft

## Назначение

Рабочая программа самостоятельного курса шведского языка на основе книги Е. Л. Жильцова «Шведский язык. Самоучитель».

## Важно

Это пока **не окончательная программа**. Количество уроков, их границы и последовательность будут определены после полного анализа исходной книги.

## Источник

Основной источник: PDF самоучителя Жильцовой.

## Методическая модель

Учебные блоки разрабатываются с использованием модели:

`.1 Введение → .2 Разбор → .3 Управляемая практика → .4 Коммуникативная задача → .5 Проверка`

Модель может адаптироваться к конкретному материалу.
