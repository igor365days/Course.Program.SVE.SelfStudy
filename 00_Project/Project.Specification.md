# Project Specification — Course.Program.SVE.SelfStudy

## 1. Назначение

Создать самостоятельную долгосрочную программу изучения шведского языка на основе книги Е. Л. Жильцова **«Шведский язык. Самоучитель» (2-е изд., 2014)**, переработав её материал в учебную систему с понятными результатами, практикой и контролем прогресса.

## 2. Отношение к Course.Program.SVE

Проект является **отдельным**.

Основной `Course.Program.SVE` не изменяется и не зависит от этого проекта.

При разработке разрешено использовать накопленный методический опыт предыдущего проекта, включая:

- декомпозицию учебного материала;
- внутренние этапы учебного блока;
- явную фиксацию состояния курса;
- переход от объяснения к управляемой практике;
- коммуникативные задачи;
- проверку достижения результата;
- работу с материалами блоками при отсутствии постоянного интернета.

## 3. Исходный материал

Основным источником содержания является PDF книги Жильцовой.

Книга не копируется в проект целиком. В проекте фиксируются её структура, учебные темы, упражнения и методически значимые элементы в объёме, необходимом для разработки курса.

## 4. Основной принцип разработки

Не принимать структуру книги автоматически как структуру курса.

Сначала проводится анализ:

`книжный урок → содержание → цели → зависимости → упражнения → предполагаемый результат`.

После анализа определяется оптимальная учебная декомпозиция.

## 5. Учебный блок

Каждый разработанный учебный блок по возможности проходит следующие этапы:

1. **Введение** — что изучаем и зачем.
2. **Разбор** — объяснение и осмысление материала.
3. **Управляемая практика** — выполнение с поддержкой.
4. **Коммуникативная задача** — применение материала в ситуации.
5. **Проверка результата** — проверка того, что учащийся действительно может выполнить заявленную задачу.

Эти этапы являются методической моделью, а не обязательным требованием одинакового объёма для каждого блока.

## 6. Принципы курса

### 6.1. Результат важнее прохождения страниц

Завершение блока определяется достижением результата, а не фактом прочтения материала.

### 6.2. Не перегружать ученика

Материал должен выдаваться такими порциями, которые реально можно освоить за одну учебную сессию.

### 6.3. Теория должна сразу работать

Грамматические и фонетические объяснения связываются с распознаванием, произношением, построением фраз и использованием языка.

### 6.4. Не маскировать неизвестное

Если исходная книга не содержит необходимых сведений, это фиксируется как пробел. Дополнительные материалы добавляются осознанно и помечаются как внешние.

### 6.5. Состояние курса должно быть однозначным

В любой момент должно быть понятно:

- какой учебный блок текущий;
- какой этап выполняется;
- что уже пройдено;
- что требует повторения;
- какое условие необходимо для перехода дальше.

## 7. Работа с аудио и другими ресурсами

Если для полноценного выполнения упражнения требуется аудио, видео или другой внешний ресурс, он должен быть отдельно указан в учебном блоке.

Отсутствие доступа к ресурсу не должно скрываться от учащегося. При необходимости предусматривается автономная альтернатива.

## 8. Версионирование

До завершения анализа исходной книги окончательная структура курса не фиксируется.

Первая версия программы после анализа получает отдельный номер версии.

Изменения программы должны быть отражены в Git и сопровождаться понятным сообщением коммита.

## 9. Критерий качества

Хороший учебный блок должен позволять ответить на вопрос:

> **Что ученик после этого блока способен сделать такого, чего не мог сделать до него?**

Если на этот вопрос нельзя дать конкретный ответ, блок требует переработки.
