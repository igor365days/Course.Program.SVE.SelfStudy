# Checkpoint Assessment Audit v1.0

**Course:** `Course.Program.SVE.SelfStudy`  
**Status:** Audit baseline  
**Scope:** 18 LCP + 5 Section CP

## 1. Executive result

The route correctly defines **18 LCP** and **5 CP**, but the current assessment definitions are not yet sufficiently specified for canonical use.

### LCP

All 18 LCP files exist and identify their source lesson, covered Unit, purpose, required competencies, success rule and remediation/recheck concept.

However, all 18 currently fail the canonical LCP definition standard in the same material way: the `Assessment components` section does not define concrete assessment tasks, expected evidence, or a verification mode for each individual mandatory component. The files therefore remain **PROVISIONAL**.

### CP

The route and course program reference **5 CP**, but no canonical CP definition files and no CP definition standard existed before this audit. A canonical `Section.Checkpoint.Definition.Standard.md` is now added. CP-1 through CP-5 definitions still need to be created.

## 3. Source-evidence constraint

The currently attached PDF contains 150 PDF pages and reaches printed book page 146. The source map assigns Lesson 13 to printed pages 140–149 and Lessons 14–18 to pages 150–202.

Therefore:

- Lessons 1–12 can be audited against the available source pages.
- Lesson 13 can only be partially source-verified from the current PDF.
- Lessons 14–18 cannot be page-verified from the current PDF.

Assessment design for unavailable lessons may be drafted from the existing project source-map/Unit definitions, but it must be labelled as **project-added assessment design** and must not be presented as page-verified source evidence.

## 4. Design principle

The next revision must not turn LCP into a larger list of Unit exercises. Each LCP should require integration and independent use of the important material of its whole lesson.

The next revision must also preserve the distinction between:

- source-derived learning content;
- project-designed assessment tasks;
- verification method;
- learner state.

## 5. Next implementation step

1. Expand LCP-01 through LCP-18 with concrete integrated tasks and per-component verification modes.
2. Mark source-validation status honestly where the current PDF does not contain the required pages.
3. Create CP-1 through CP-5 as independent integrated section assessments.
4. Re-audit the completed checkpoint definitions against both checkpoint standards and the source-availability constraint.
