## 5. Verification audit

The canonical CP standard requires, for every mandatory component:

1. concrete task;
2. expected evidence;
3. verification mode;
4. success criterion.

The earlier CP definitions lacked explicit per-component expected evidence and success criteria. All five CP files were updated to close that gap.

Verification modes remain within the canonical allowed set: `AI_VERIFIED` and `USER_CONFIRMED`.

## 6. Integration audit

All CPs contain a task explicitly requiring transfer to a new situation:

- CP-1: C3/C4;
- CP-2: C4;
- CP-3: C5;
- CP-4: C4;
- CP-5: C5.

Therefore CPs are not merely collections of preceding LCPs.

## 7. Remediation / recheck audit
